# Assembly Auto Helper

## Project Overview
This project is a Python-based web automation tool designed to help users quickly and efficiently submit "opposition" opinions to multiple legislative bills on the Korean National Assembly website. 

It consists of two main components:
1. **`fetch_links.py`**: A scraping script that fetches a list of legislative bills for a specific date from the `vforkorea.com` API. It outputs a formatted list of dictionaries containing URLs and predefined opposition messages.
2. **`main.py`**: The core automation script powered by Selenium. It reads the list of tasks (URLs and messages), opens a browser session, waits for the user to manually log in (and handle any initial Captcha), and then programmatically iterates through the tasks in new tabs to inject the opposition messages using JavaScript.

## Technologies Used
* **Python**
* **Selenium**: For web browser automation and interaction.
* **webdriver-manager**: For automatic management of ChromeDriver binaries.
* **requests**: For making HTTP requests to external APIs.
* **BeautifulSoup**: For HTML parsing (if needed).

## Building and Running

### Prerequisites
1. Ensure you have Python installed (preferably 3.x).
2. Activate your virtual environment if you are using one (e.g., `source .venv/bin/activate`).
3. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```
   *(Note: You might also need to install `requests` and `beautifulsoup4` if they are not listed in `requirements.txt` but are used in `fetch_links.py`)*

### Usage

**1. Fetching Target Links**
Use the `fetch_links.py` script to get the target URLs for a specific deadline date.
```bash
# Fetch links for a specific date (e.g., 2026-03-30)
python fetch_links.py 2026-03-30

# Or run interactively and provide the date when prompted
python fetch_links.py
```
Copy the output generated by this script and paste it into the `tasks` array in `main.py`.

**2. Running the Automation**
Run the main automation script.
```bash
python main.py
```
*   The script will launch a Chrome browser and navigate to the first bill's page.
*   **Important:** You must manually log in to the National Assembly website in the opened browser window.
*   Once logged in and on the opinion registration page, return to your terminal and press `Enter` to start the automated multi-tab processing.
*   The script will open new tabs for each task, fill in the title and message, and focus on the Captcha field. You will need to manually solve the Captcha and submit the form for each tab.

## Development Conventions
*   **Browser Profiles:** The automation script uses temporary Chrome profiles (`user-data-dir`) generated via `tempfile.mkdtemp` for each run to avoid session locking and conflicts.
*   **Stealth Techniques:** The script employs various Selenium options (e.g., `--disable-blink-features=AutomationControlled`, excluding `enable-automation` switches) to reduce the likelihood of being detected as a bot.
*   **JavaScript Injection:** To bypass complex UI interactions and speed up the process, form values (title and content) are set using `driver.execute_script()` rather than traditional Selenium `send_keys()`.
*   **API Interactions:** The `fetch_links.py` script mimics browser behavior by explicitly managing sessions, setting comprehensive HTTP headers, and handling specific payload structures (`start`, `size`, `keyword`) to bypass the target API's Web Application Firewall (WAF).
